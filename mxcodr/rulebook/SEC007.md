# SEC007 — anonymous users cannot read every row of an entity (DIVD-2022-00019)

## What it checks
Anonymous users cannot read all records of an entity: the access rule needs an XPath that limits them.

## Fix
An XPath constraint on the anonymous role's read rule, or revoke the grant if the data is not public.
