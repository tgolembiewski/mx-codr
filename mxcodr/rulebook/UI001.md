# UI001 — a data grid filters itself, not through a hand-built filter bar

## What it checks
A data grid is filtered with the filters inside its columns, not with a home-made filter bar of text boxes and checkboxes above it.

## Fix
One filter in the column (`textfilter`, `numberfilter`, `datefilter`, `dropdownfilter`, for an association `(Association: ..., datasource: database ..., CaptionAttribute: ...)`); never a filter bar over a helper entity.
