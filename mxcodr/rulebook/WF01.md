# WF01 — a flow that completes a workflow task checks the user is one of its targets
step: paths
level: block
check: check_paths.cjs#findings
key: document

## What it checks
A microflow that approves or rejects a workflow task first checks that the person clicking is someone the task was assigned to. Without that check, anyone allowed to run the microflow can decide someone else's task.

## Fix
Retrieve the task's `System.WorkflowUserTask_TargetUsers`, refuse when `[%CurrentUser%]` is not in it; grant the flow only to the roles the task targets.
