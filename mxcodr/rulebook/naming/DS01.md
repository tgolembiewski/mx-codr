# DS01 — a list takes its rows from the database, not from a flow that only retrieves them

## What it checks
A data grid, list view or gallery whose data source is a microflow that only retrieves rows uses a Database source instead. The database then pages, sorts and filters, which is much faster.

## Fix
The `DataSource: database ...` it prints; `'[%CurrentObject%]'` for the enclosing object -- blocks DONE.
